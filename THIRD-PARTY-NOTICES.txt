3. MULTIWFN

Multiwfn is a program by Tian Lu (http://sobereva.com/multiwfn). It is
not included with OmniWfn. The functions of OmniWfn that run Multiwfn
use a copy of Multiwfn that you install yourself, under Multiwfn's own
license. OmniWfn is not made, endorsed or supported by Multiwfn's
author.

OmniWfn implements many of Multiwfn's analysis methods and conventions,
writes files in Multiwfn's formats, reproduces the text of Multiwfn's
menus so that Multiwfn keystroke paths can be answered, and includes
data distributed with Multiwfn 2026.9.20:

  - spherically averaged radial densities of free atoms and ions
    (Multiwfn's examples/atmrad), for Hirshfeld-I;
  - free-atom wavefunctions, H-Kr (Multiwfn's examples/atomwfn);
  - sphericalized free-atom densities and Slater-function fits
    (atmraddens.f90), and atomic radii including Tian Lu's modified
    CSD radii (define.f90).

As Multiwfn's license asks of code that incorporates any part of
Multiwfn, its original papers are cited here:

  Tian Lu, Feiwu Chen, J. Comput. Chem., 33, 580-592 (2012)
  Tian Lu, J. Chem. Phys., 161, 082503 (2024)

If you publish results obtained with OmniWfn's Multiwfn-based methods,

4. LEBEDEV-LAIKOV ANGULAR GRIDS

OmniWfn's integration grids use the Lebedev angular quadratures, with
parameters from the Lebedev-Laikov code by D. N. Laikov and
C. van Wuellen, whose users are asked to cite:

  V. I. Lebedev, D. N. Laikov, "A quadrature formula for the sphere of
  the 131st algebraic order of accuracy", Doklady Mathematics, 59,
  477-481 (1999)
